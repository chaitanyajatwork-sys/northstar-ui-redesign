# Northstar University — Website UI Redesign

#Live Link-https://chaitanyajatwork-sys.github.io/northstar-ui-redesign/#

A responsive website redesign created for a **UI/UX Design Internship Task**. The goal was to transform a basic, outdated university website into a modern, clear and user-friendly experience.

## Project Goal
The original concept suffered from weak visual hierarchy, dense navigation, inconsistent spacing, dated presentation and unclear calls-to-action. This redesign focuses on clarity, accessibility, modern visual language and a smoother content journey.

## Key UI/UX Improvements
- Clear, sticky navigation with a prominent **Apply Now** CTA
- Strong hero hierarchy with concise messaging and two clear actions
- Consistent spacing, typography and reusable visual components
- Program cards that make course discovery easier
- Scannable university statistics and benefit sections
- Dedicated campus and student-story sections to build trust
- Responsive mobile navigation and layouts
- Subtle scroll-reveal interactions without distracting from content
- High-contrast buttons and readable body copy

## Design Direction
The interface uses an editorial-inspired visual system with warm neutral backgrounds, high-contrast black, energetic lime accents and purple highlights. Rounded photography is balanced with structured cards and grids to keep the experience youthful but professional.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans & Manrope)
- Unsplash images (remote image URLs)

## Files
- `index.html` — page structure and content
- `style.css` — complete responsive design
- `script.js` — mobile navigation and reveal interactions

## Note
**Northstar University is a fictional institution created solely for this UI redesign exercise.** The content and statistics are concept data and are not intended to represent a real university.
